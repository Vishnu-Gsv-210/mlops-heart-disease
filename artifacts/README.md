# Artifacts

Everything in this repository's model and reporting outputs is generated by
reproducible commands — nothing here is hand-written. This file explains what
each output directory contains and how to regenerate it.

## `models/`

| File | Contents |
|---|---|
| `heart_disease_pipeline.joblib` | The selected, fitted scikit-learn pipeline: leakage-safe preprocessing (imputation + scaling/one-hot encoding) plus the winning classifier, serialized together so serving needs no separate transformer |

Regenerate:

```bash
python -m src.heart_disease.train        # or: make train
```

The API (`uvicorn src.heart_disease.api:app`) loads this file at first request;
it fails with 503 if the file is missing, so train before serving.

## `reports/`

| Path | Contents |
|---|---|
| `reports/artifacts/eda_summary.json` | Row counts, class balance, missing-value summary from EDA |
| `reports/artifacts/comparison.json` | Side-by-side test metrics for Logistic Regression vs Random Forest |
| `reports/artifacts/model_card.json` | Selected model card: family, hyperparameters, CV and test metrics |
| `reports/artifacts/training_summary.json` | Full training run summary incl. run IDs |
| `reports/artifacts/*_classification_report.json` | Per-class precision/recall/F1 for each candidate |
| `reports/figures/class_balance.png` | Binary target distribution |
| `reports/figures/feature_distributions.png` | Histograms of all 13 features |
| `reports/figures/correlation_heatmap.png` | Feature + target correlation matrix |
| `reports/figures/roc_curve.png` | Held-out ROC curve of the selected model |
| `reports/figures/confusion_matrix.png` | Held-out confusion matrix |
| `reports/final_report.md` | Draft narrative for the written report |
| `reports/results_summary.json` | Machine-readable roll-up consumed by the report generator |

Regenerate all figures and summaries (idempotent; uses the cleaned dataset in
`data/processed/`, rebuilding it from raw data if absent):

```bash
make eda                 # EDA figures + eda_summary.json
python -m src.heart_disease.train   # model, metrics, model card, ROC/confusion plots
python scripts/run_pipeline.py      # or run everything end-to-end in one command
python scripts/generate_report.py   # compile report_generated.pdf from real artifacts + screenshots
```

`reports/artifacts/` is owned by the pipeline: metrics come only from actual
runs. If a file is missing, rerun the command that produces it rather than
editing JSON by hand.
